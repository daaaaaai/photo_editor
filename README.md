# かんたんフォトエディタ 🖼️

HTML と JavaScript のみで動作するブラウザ完結型の写真編集ツールです。
サーバーとは一切通信せず、画像はすべてブラウザの中だけで処理されます。

## 機能

- **画像の読み込み** — ファイル選択 / ドラッグ&ドロップ / クリップボード貼り付け（Ctrl+V）に対応
- **✂️ 切り出し（クロップ）** — ドラッグで範囲を選択し、その部分だけを切り出す
- **🔳 モザイク** — ドラッグした範囲に、粗さを調整できるモザイクをかける
- **☀️ 明るさ・コントラスト** — スライダーで調整して適用
- **T テキスト** — 画像の上に文字を入れる（下記）
- **↗ 矢印** — ドラッグで矢印を描く。太さと色を指定できる
- **↩ もどす（Undo）** — 直前の操作を取り消し（Cmd/Ctrl+Z 対応）
- **🔄 元画像に戻す** — 読み込み直後の状態にリセット
- **📥 保存** — 編集結果を PNG としてダウンロード

### テキストについて

- 画像をクリックした位置に入力枠が出ます。**左上のつまみをドラッグすると位置を動かせます。**
- **サイズ** は 8〜400px。大きな写真でも読める大きさにできます。
- **書体** はゴシック / 明朝（各太字）/ 等幅に加え、丸ゴシック・教科書体・ポップ体を用意しています。
  ただし**端末に入っていない書体は選択肢に出しません**。未搭載の書体を並べても既定のゴシックに
  落ちて「見た目が同じ選択肢」が増えるだけなので、実際に差が出るものだけを表示します。
  そのため選べる書体は OS によって変わります（Windows / macOS のほうが多くなります）。
- **背景色** を文字の背後に敷けます。既定は黒。「背景」のチェックを外すと背景なしになります。
- 確定は Enter かチェックボタン、改行は Shift+Enter、取り消しは Esc か ✕ です。

## 使い方

```
index.html をブラウザで開くだけ
```

ビルド・インストール不要です。

## プライバシーについて

読み込んだ画像はサーバーにアップロードされません。
すべての処理（切り出し・モザイクなど）はブラウザ内の Canvas API で完結します。
